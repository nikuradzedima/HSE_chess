# Шахматы (заготовка под свой вариант)

Открыть `index.html` в браузере — сервер не нужен. Двое за одним устройством.

Сейчас — классические правила полностью (рокировка, на проходе, превращение, мат/пат,
50 ходов, троекратное повторение, недостаточный материал), подсветка ходов, клик и
перетаскивание, отмена хода, запись партии, авто-поворот доски, инструкция (кнопка «?»).

## Свои картинки и озвучка
Всё в `theme.js`:
- `pieces` — путь к картинке для каждой фигуры (`wK`…`bP`), файлы в `assets/pieces/`. PNG с прозрачным фоном, квадрат.
- `sounds` — звук на событие (`move`, `capture`, `check`, `checkmate`…), файлы в `assets/sounds/`.
  Массив = случайная реплика; `"capture:wN"` — отдельный звук для конкретной фигуры.
- Пустые поля — стандартные символы и синтезированные звуки.

## Структура
- `js/engine.js` — правила; фигуры заданы данными (`PIECES`: slide/leap), сюда встраивается необычная механика.
- `js/ui.js` — доска и управление, `js/sound.js` — звук, `css/style.css` — оформление.
